LOCAL CONNECTION

把这一片玻璃，送进 Figma。

首次连接需要本地桥接服务和配套开发插件。之后保持插件运行，即可在网站一键导入。

  1. 下载项目，在 Node.js 20+ 环境运行 npm run bridge。
  2. Figma 桌面版 → Plugins → Development → Import plugin from manifest，选择 figma-plugin/manifest.json。
  3. 运行插件；将终端中的配对码分别填入插件和下方。允许浏览器访问本地网络。
↓ 下载插件与连接服务（含说明）
